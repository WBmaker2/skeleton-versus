# Skeleton Versus — 카메라 2인 대전

카메라 1대로 즐기는 세로 2분할 실시간 대전 18종. 브라우저에서 설치 없이 동작합니다.

## 시작

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173/` 접속. 대전 고르기에서 골라 시작하세요.
카메라 권한을 허용하세요. 둘이 나란히 2.5~3.5m 거리에서 화면에 다 보여야 합니다.
서로 1m 이상 띄어 서세요 (중앙선을 넘으면 점수가 멈춥니다).
혼자서도 연습할 수 있어요 (한 명만 보여도 내 점수는 올라감).

## 대전 (18종, 60초)

반응·순발력:

- `#/versus-mole` 두더지 대전: 바닥은 내려찍고 옆쪽은 휘둘러 잡기 (+10). 5연속이면 상대 두더지 가속 5초.

- `#/versus-fruit` 과일 베기 대전: 손으로 과일 베기 (+10). 3콤보마다 상대에게 썩은 과일 (-5). 폭탄 -15점.
- `#/versus-star` 별잡기 대전: 별에 손대고 0.3초 유지 (+10). 3콤보마다 먹별 (-5) 전송.
- `#/versus-balloon` 풍선 대전: 이마로 풍선 받기 (+5). 3콤보마다 풍선 선물 전송.
- `#/versus-zombie` 좀비 대전: 반쪽 3레인 회피 (+10). 5연속이면 상대 좀비 가속 5초.
- `#/versus-punch` 펀치 대전: 타겟을 휙 쳐야 인정 (+2). 10연속이면 상대 타겟 축소 5초.
- `#/versus-clap` 박수 대전: 떼었다 합쳐야 1회 (+3). 20연속이면 상대 판정 강화 5초.

힘·지구력:

- `#/versus-tug` 스쿼트 줄다리기: 앉았다 일어나면 줄 당기기. 박자 Perfect는 2칸. 5연속 Perfect면 파워 당기기 3초.
- `#/versus-run` 달리기 GP: 제자리 무릎 들기 2스텝=1m (+5). 막판 10초 스프린트 2배.
- `#/versus-power` 파워 줄다리기: 팔 굽혔다 펴면 당기기 1회. 5연속이면 상대 화면 흔들림 3초.

정확도·균형:

- `#/versus-abc` ABC 대전: 같은 글자 1초 유지. 먼저 완성 +20과 안개 3초, 나중 +10.
- `#/versus-balance` 균형 대전: 한발 버티기 1초당 +2 합산. 먼저 20초 누적하면 상대 화면 흔들림 3초.
- `#/versus-laser` 레이저 대전: 2초 안에 레이저 피하기 (+10). 닿으면 -5점. 5연속이면 상대 레이저 가속 5초.

두뇌·리듬:

- `#/versus-math` 수학 달리기 대전: 자기 반쪽 3구역으로 이동 + 손들기. 먼저 정답 +20과 안개 3초, 나중 +10, 오답 -5점.
- `#/versus-simon` 사이먼 대전: 같은 지시에 답하기. 먼저 +20과 안개 3초, 나중 +10.
- `#/versus-duo` 별자리 대전: 별 순서대로 잇기. 먼저 완성 별 개수 × 10과 안개 3초, 나중 × 5.
- `#/versus-dance` 댄스 대전: 같은 동작 따라하기. 먼저 적중 +15, 나중 +10. 3연속이면 상대 박자 단축 5초.
- `#/versus-memory` 기억 릴레이 대전: 3포즈 순서 재현. 먼저 완성 +30과 안개 3초, 나중 +15.

## 조작법

- 카메라: 두 사람이 좌우로 나란히, 전신이 보이게 2.5~3.5m
- 한 명만 보이면 그쪽 점수만 오르고 안내가 나옵니다 (혼자 연습 가능)
- 중앙선을 넘으면 점수가 멈추고 경고가 나옵니다
- 대전 종료 후 결과 화면에 전적 표시, `다시 대전` 버튼으로 바로 재시작
- 앉아서도 가능: 과일·수학·별·사이먼·ABC·댄스·풍선·좀비·펀치·박수·균형·릴레이·레이저·두더지 (줄다리기·달리기·파워는 서서만)
