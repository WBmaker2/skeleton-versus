# 3차 확장 계획 (확정)

0.8.0 상체·정적 4종(A5·A6·C2·D4) + 0.9.0 전신 3종(B3·B5·C4).
제외 유지: B2·B4·C1·D5, 요가·분리수거. 1P 코드는 읽기 전용 참조.
실패 시 중단·보고.

## 공통 전제

- 60초·세로 2분할·자기 반쪽·공유 시드 미러·중앙선 가드 그대로.
- 속도 판정은 어깨너비 정규화 (px/s ÷ 어깨너비).
- 손 뻗기 종목은 몸통 기준 가드라 정상 플레이에 경고 안 뜸.

## A5 펀치 러시 (`versus-punch`, 쉬움)

- 반쪽 안쪽 60% 구역에 타겟 1개씩 (공유 순서·미러).
- 손목이 타겟에 닿는 순간 속도가 4어깨너비/s 이상이면 펀치 인정 +2점, 느리면 무효.
- 맞은 뒤 같은 자리 재생성 + 연타 방지 쿨 300ms.
- 10연속 펀치마다 상대 타겟 축소 0.7배 5초 (`tiny` 신설).
- 도움말에 "옆이 아닌 앞을 향해" 1줄.

## A6 박수 스파크 (`versus-clap`, 쉬움)

- 양손 거리 < 0.3어깨너비로 합쳐졌다 벌어져야 1회 +3점 (붙인 채로 카운트 안 됨).
- 20연속마다 상대 박수 판정 강화 5초 (`strict` 신설: 0.3→0.2배율).

## C2 한발 균형왕 (`versus-balance`, 쉬움)

- 시작 게이트: 양쪽 발목이 보여야 시작.
- 한쪽 발목이 반대 무릎 위로 올라가면 측정 시작, 1초당 +2점 합산.
- 높이차 소실 시 리셋 (미검출 0.5초 유예, 0.15어깨너비 히스테리시스).
- 먼저 누적 20초 도달하면 상대 화면 흔들림 (`shake` 신설, 3초).

## D4 기억 포즈 릴레이 (`versus-memory`, 중간)

- 3개 포즈(10종 중, 직전 라운드와 중복 제외)를 순서대로 보여주고 재현하면 +30점.
- 순서 틀리면 해당 라운드 처음부터 (감점 없음).
- 먼저 완성하면 안개 3초 (fog 재사용). 순서 표시 UI 3칸 신규.
- 판정 후 300ms 쿨 + 같은 판정 2회 연속 확인 후 인정.

## B3 제자리 달리기 GP (`versus-run`, 중간, 순수 레이스)

- 무릎 y 파형 피크를 좌우 교대로 세어 2스텝=1m 환산, 1m당 +5점.
- 막판 10초 스프린트 ×2 보너스. 공격 없음.
- 무릎 가림 보조: 어깨上下 진동 + 피크 임계 0.2어깨너비. 서서만 명시.

## B5 줄다리기 파워 (`versus-power`, 중간)

- 팔꿈치 각도 90°↔150° 1왕복 = 당기기 1회, 게이지 2칸 전진. ±30 먼저 넘기면 승리.
- 줄 오버레이 재사용. 5연속 왕복이면 상대 화면 흔들림 (`shake`). 앉음 가능.
- 팔꿈치 미검출 시 어깨·손목 벡터로 대체 추정.

## C4 레이저 터널 (`versus-laser`, 중간)

- 가로 레이저 3높이가 내려오고, 머리·몸통이 닿으면 -5점·콤보 리셋, 통과 1개 +10점.
- 레이저 패턴 공유 시드·미러. 5연속 통과마다 상대 레이저 1.5배속 5초 (`rush` 재사용).
- 원-선분 거리 충돌 판정 신규.
