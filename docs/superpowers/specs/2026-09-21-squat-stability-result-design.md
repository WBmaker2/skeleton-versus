# 앉은 자세 안정화 + 등록 후 오버레이 정리 — 설계 기록

- 날짜: 2026-09-21
- 상태: 구현됨 (사용자 요청 2건)
- 종류: bounded (기존 흐름 수정 2건, 서로 독립)

## 1. 앉은 자세 깜빡임 방지

- 원인: 발목이 프레임 밖으로 나가면 무릎각이 180도 기본값으로 떨어져 깊이가 0으로 튐. 앉은 상태에서 서있음/앉음이 왔다갔다 함.
- 설계 (`src/game/squat-runner.ts`):
  - `depthOf()`: 발목이 있으면 기존 무릎각, 없으면 허벅지-연직선 기울기(0°=섬, 70°=완전 앉음)로 추정. 쓸 키포인트가 하나도 없으면 null → 이전 깊이 유지.
  - `ducking` 히스테리시스: 0.6 진입 / 0.35 해제. 중간 구간에서는 이전 상태 유지.
  - 아바타·`cueText`·장애물/코인 판정은 `ducking`으로 통일 (안내와 판정이 어긋나지 않음).
  - 횟수 인정(`isDown`+`duck` 점수)은 기존 300ms 홀드 유지.
- 테스트: 발목 없음 유지 / 키포인트 없음 유지 / 중간 구간 히스테리시스 3케이스.

## 2. 등록 완료 후 오버레이 정리

- 문제: 점수 등록 후에도 등록 폼이 계속 보임.
- 설계: `src/ui/leaderboard.ts`에 `resultFormHTML`/`resultDoneHTML` 추출. `src/main.ts` 등록 submit 성공 시 오버레이를 완료 문구+다시 도전으로 교체하고 `wireAgain()` 재연결.
- 테스트: 폼 상태·완료 상태 문구 2케이스.
