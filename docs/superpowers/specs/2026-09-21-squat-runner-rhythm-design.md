# 스쿼트 러너 리듬 박자 — 설계 기록

- 날짜: 2026-09-21
- 상태: 승인됨 (사용자 선택: 천천히 2.0초 시작)
- 종류: bounded (기존 `src/game/squat-runner.ts` 개편, 하이브리드에 이은 2차)

## 1. 문제

- 하이브리드(장애물+코인+속도) 이후에도 "언제 앉아야 하는지" 신호가 없어 박자가 제각각.
- 캐릭터 좌측 고정·장애물 우→좌 이동은 이미 구현됨 (`playerX = width*0.22`, 우측 끝 스폰). 이번 작업은 변경 없음.

## 2. 설계 (채택: 박자 동기 스폰)

- **메트로놈:** `beatInterval = max(1400, 2000 - 경과초*10)`ms. 2.0초 시작, 60초에 1.4초까지 가속. 상단 박자 진행 바+박자 순간 펄스+BPM 표시.
- **박자 판정:** 스쿼트 1회마다 최근 박자와 어긋남으로 Perfect(±150ms, 15점) / Good(±350ms, 10점) / 어긋남(5점). 기존 `duck` 이벤트 재사용 → 파티클·효과음 그대로, 기존 테스트(타입만 확인) 유지.
- **박자 동기 스폰:** 이동시간(우측 끝→캐릭터 ≈ 1박자)을 이용해 박자 N 스폰이 박자 N+1에 도착. 홀수 박자→장애물(앉아 회피), 짝수 박자→낮은 코인(앉은 채 획득), 박자 사이→높은 코인(선 채 획득). 기존 시간 기반 스폰 타이머 제거.
- **공개 API 추가:** `beatIntervalMs`, `beatClockMs` (테스트용 읽기 전용).
