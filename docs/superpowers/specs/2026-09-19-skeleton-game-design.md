# 스켈레톤 카메라 운동 게임 웹앱 — 설계 문서

- 날짜: 2026-09-19
- 상태: 승인됨 (사용자 승인: 하이브리드 추천안으로 구현)
- 대상: 랩탑 / 태블릿 / 크롬북, 최신 Chrome/Edge/Safari
- 환경: 초등 교실 수업용 + 가정 개인 운동용 (모드 전환)

## 1. 목적과 성공 기준

### 목적
- 전면 카메라만으로 실시간 스켈레톤을 분석해 즐겁게 움직이는 웹 게임 제공
- 학생들이 수업 중·방과 후에 신체 활동을 하도록 유도
- 교육 연계 (영어, 수학, 환경) 포함

### 성공 기준
- 설치 없이 URL/QR로 10초 내 시작
- 저사양 크롬북에서 15fps 이상, 판정 지연 <200ms
- 카메라 영상 외부 전송 없음 (온디바이스 처리)
- 앉음(책상) 모드와 선(전신) 모드 모두 지원
- 4종 프로토타입 플레이 가능: 과일닌자 몸버전, 스쿼트러너, 몸으로ABC, 점프수학퀴즈

## 2. 게임 아이디어 목록 (12선)

### 우선 구현 4종
1. **과일 닌자 몸버전**: 양 손목 궤적으로 과일 베기, 폭탄은 양손 X자로 회피 (접촉 시 콤보 리셋 + 15점 감점). 어깨 스트레칭·순발력. 교실=앉아 팔만, 집=전신 점프 베기.
2. **스쿼트 러너**: 무릎 각도 140°→100° 이하로 앉았다 일어서기로 장애물 통과. 하체·심폐. 교실=의자 스쿼트, 집=풀 스쿼트+점프.
3. **몸으로 ABC**: T/Y/O/L 등 팔+다리 포즈로 알파벳·단어 만들기. 각도 유사도 판정. 영어 연계.
4. **점프 수학 퀴즈**: `7+8=?` 3지선다 중 정답 구역으로 몸 이동·손들기. 수학·과학 연계, 팀전 가능.

### 확장 8종
5. 별잡기 스트레칭 (랜덤 별 터치, 유연성)
6. 풍선 헤딩 (머리+어깨 중심 유지, 코어)
7. 좀비 스텝 (좌우 스텝 회피, 민첩성)
8. 리듬 댄스 카피 (4박자 포즈 따라하기)
9. 사이먼 AI 선생님 (음성 지시+포즈, 듣기·반응)
10. 요가 거울 (나무·전사자세 5초 버티기, 균형)
11. 2인 별자리 (2인 협동 선 연결)
12. 분리수거 스트레칭 (몸 기울여 분류, 환경교육)

교실 안전: 1/4/5/9/12는 책상 자리에서 가능. 점프·스쿼트는 매트 1장 공간 확보.

## 3. 기술 방식 (채택: C 하이브리드)

### A. TF.js MoveNet Lightning + 정적 웹앱 (기반)
- 17 keypoints, 크롬북·구형 랩탑 25~30fps
- 단점: 손가락 정밀동작 약함

### B. MediaPipe Pose Landmarker 33점 (정밀용)
- ABC·요가 정밀 포즈에 유리
- 단점: 저사양에서 10~15fps로 끊김, 태블릿 발열

### C. 하이브리드 (채택, Recommended)
- 기본 엔진 MoveNet으로 4종 공통화
- `몸으로 ABC`만 MediaPipe 33점으로 전환 (엔진 교체 가능 구조)
- PWA: 설치·오프라인·전체화면 지원
- 개인정보: 영상 서버 전송 없음, 점수만 로컬 저장
- ScoreBoard 콤보 보너스는 +combo*5 (테스트가 계약). MediaPipe 어댑터는 landmarkName()으로 canonical 이름(shoulders/wrists 등)을 방출하여 BodyABC와 연결.

선택 이유: 학교망·개인정보·저사양 대응을 동시에 만족. 속도(MoveNet)와 정밀도(MediaPipe)를 게임별로 구분 사용.

## 4. 아키텍처

```
Camera(720p 요청) → PoseEngine(MoveNet/MediaPipe, 30fps 스로틀)
→ Calibration(신장·중앙 보정) → GameLogic(게임별 판정)
→ Renderer(Canvas 오버레이) → Feedback(점수·사운드·랭킹)
```

- 단일 웹앱, 게임 모드 전환식 (URL hash: `#/fruit`, `#/squat`, `#/abc`, `#/math`)
- 프레임워크: Vite + TypeScript + TensorFlow.js + MediaPipe Tasks Vision, Canvas 2D 렌더
- PWA manifest + service worker (오프라인 캐시: 모델은 최초 로드 후 캐시)
- 서버 없음 (정적 호스팅: GitHub Pages / Cloudflare Pages / 학교 인트라넷)

## 5. 컴포넌트

- **PoseEngine**: `estimate()` 추상화, MoveNet↔MediaPipe 어댑터, 저사양시 480p·15fps 자동 폴백, 거울모드 좌우반전 처리
- **Calibrator**: 시작 3초 T자세로 어깨너비·몸중심 측정, 앉음/섬 자동 분기, 재보정 버튼
- **Games (공통 API: start/stop/tick/score)**:
  - FruitNinja, SquatRunner, BodyABC, MathJump
  - 공통 타이머·콤보·난이도(쉬움/보통/어려움) 모듈 공유
- **Classroom**: 닉네임+점수 로컬 랭킹(localStorage), 교사 화면용 QR 입장, 소리 ON/OFF, 자막 지원
- **Renderer**: 스켈레톤 오버레이 ON/OFF, 색맹 대응 색상, 큰 폰트·고대비 (교실 프로젝터 고려)

## 6. 데이터 플로우

1. `getUserMedia` 권한 요청 → 미리보기 + 안내 오버레이
2. Calibrator 3초 측정 → `scale`, `centerX`, `mode(seated|standing)` 저장
3. 매 프레임: keypoints → 스무딩(One-Euro/EMA) → 정규화(어깨너비 기준) → 게임별 판정 함수
4. 판정 이벤트 → 점수·콤보·효과음·파티클 → 로컬 랭킹 갱신
5. 종료 → 결과 화면 (움직임량, 최고기록, 다시하기·교사공유)

저장 데이터: 닉네임, 점수, 난이도, 모드. 영상·원시 좌표는 저장하지 않음 (세션 메모리만).

## 7. 게임별 판정 로직 초안

- **과일닌자**: 손목 속도벡터가 과일 히트박스 통과 시 절단. 폭탄 0.5초 내 양손 교차(X) 유지 시 회피, 아니면 콤보 리셋 + board.add(-15) 15점 감점. 과일 스폰 0.9초 간격 (난이도별 조정).
- **스쿼트러너**: 무릎각도(엉덩이-무릎-발목) 140°→100° 이하 0.3초 유지 = 숙이기/점프 트리거. 어깨 y 급상승 보조 신호. 연속 10회 시 휴식 안내.
- **몸ABC**: 어깨-팔꿈치-손목·고관절 각도 템플릿과 코사인 유사도 0.8 이상 1.0초 유지 = 인정. 상체모드(앉음)에서는 하체 가중치 0. BodyABC.mode 필드로 seated/standing 보관 (HUD 표시, 향후 가중치 분기용).
- **수학퀴즈**: 몸중심 x가 정답존 0.6초 체류 OR 손목>어깨 0.5초 거수로 확정. 오답 시 흔들림 피드백, 3초 후 다음 문제. 문제셋 JSON 교체 가능 (교사 커스텀).

## 8. 에러 처리

- 카메라 거부/없음: 키보드·터치 폴백 모드 안내 ("스페이스바로도 플레이 가능")
- 사람 없음 / 2인 이상: "한 명만 중앙에 서주세요" 오버레이, 게임 일시정지
- 저조도·역광: 대비 경고 + 노출 가이드, 판정 임계값 완화 옵션
- 저사양 (fps<12 3초 지속): 해상도 480p·추론 15fps로 자동 하향, 파티클 감소
- 태블릿 세로모드: 상체모드 자동 전환, 히트박스 재배치
- 모델 로드 실패: CDN 재시도 2회 → 오프라인 캐시 → 실패 안내 + 키보드 모드

## 9. 테스팅

- 매트릭스: 크롬북(저사양) / 윈도우 랩탑 / 안드로이드 태블릿 / iPad 각 1대 × 앉음/섬 × 1.5m/2.5m
- 목표: 15fps 이상, 판정 지연 <200ms, 5분 연속 플레이 발열·프리즈 없음
- 수동 체크: T자세 보정 성공률, 스쿼트 10회 인식률, ABC 5자 인식률, 퀴즈 오입력률
- 접근성: 자막·효과음 분리, 색맹 모드, 키보드 완주 가능 여부
- 프라이버시: 네트워크 탭에서 영상 외부 전송 없음 확인

## 10. 비범위 (YAGNI)

- 계정·서버 랭킹·결제 제외 (로컬 랭킹만)
- 멀티플레이어 실시간 대전 제외 (턴제·팀합산만)
- 커스텀 아바타·스킨 상점 제외
- 서버 AI 코칭 리포트 제외 (점수·움직임량 요약만)
