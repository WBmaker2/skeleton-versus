# 리더보드 병합 + 스쿼트 반응 개선 — 설계 기록

- 날짜: 2026-09-21
- 상태: 구현됨 (사용자 요청 2건)
- 종류: bounded (기존 흐름 수정 2건, 서로 독립)

## 1. 리더보드 중복 이름 최고점 병합

- 문제: 같은 이름으로 여러 번 등록하면 리더보드에 중복 행이 쌓임.
- 설계: 앞뒤 공백 제거 이름 기준 1행. `saveScore` 시 기존보다 높을 때만 교체(날짜 갱신), 낮으면 기존 기록 반환(등록 모달 하이라이트 정합). `readList`에서 병합하므로 구버전 저장값의 중복도 읽을 때 정리됨. 관리자 수정으로 생긴 중복도 다음 읽기 때 정리.
- 동점: 먼저 저장된 행 유지. 대소문자·동명이인은 구분하지 않음(точный 일치만 병합).
- 파일: `src/game/storage.ts`, `tests/storage.test.ts` 4케이스.

## 2. 스쿼트 캐릭터 반응 속도 개선

- 문제: 아바타가 `isDown`(300ms 홀드 후 반전)으로 그려져 몸보다 ~0.3초 늦게 앉음.
- 설계: 시각·판정과 횟수 인정을 분리.
  - `squatDepth` 0~1을 매 프레임 무릎각에서 즉시 계산 (150°=섬, 95°=완전 앉음).
  - 아바타 크기·`cueText`·장애물/코인 판정은 `depth >= 0.5`로 즉시 반응.
  - 횟수 인정(`isDown`+`duck` 점수)은 기존 300ms 홀드 유지 (오인정 방지).
- 트레이드오프: 빠른 딥(홀드 없음)으로 바를 피하면 `dodge`가 나간다. 의도된 반응성으로 판단 (몸이 실제로 숙었으면 인정).
- 파일: `src/game/squat-runner.ts`, `tests/squat-runner.test.ts` 2케이스.
