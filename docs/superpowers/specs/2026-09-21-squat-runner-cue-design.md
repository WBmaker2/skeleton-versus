# 스쿼트 러너 다음동작 예고 — 설계 기록

- 날짜: 2026-09-21
- 상태: 승인됨 (사용자 선택: 다음동작 예고+화살표)
- 종류: bounded (`src/game/squat-runner.ts` draw 위주 개편)

## 1. 문제

- 노란 박자 바는 "박자가 온다"는 알림이지 "앉아라/일어서라"는 지시가 아니라서, 언제 앉고 일어설지 알 수 없음.
- 스쿼트는 앉기+일어서기 2동작인데 신호가 1개라 모호.

## 2. 설계 (채택: 예측형 예고 + ↓↑ 화살표)

- **룰 고정:** 박자 순간 = 앉는 순간, 박자 사이 = 일어나는 시간.
- **예고 라벨** (`cueText()` 신설, draw가 그대로 그림):
  - 앉아있으면 → `일어서세요!`
  - 서있고 박자까지 0.35초 초과 → `앉기까지 {N}초`
  - 서있고 박자까지 0.35초 이내 → `지금 앉아!` (크게)
- **박자 바 구간 표시:** 앉을 타이밍 윈도우(끝 ±350ms 구간)를 주황으로, 나머지는 노랑. 작은 캡션 `일어나` / `앉아!`.
- **월드 화살표 + 색 통일:** 앉을 것(바·낮은 코인)=주황+`↓`, 설 것(높은 코인)=하늘+`↑`.
- **수치 정합:** `지금 앉아!` 윈도우(±350ms)에 앉으면 기존 판정상 최소 Good 보장.

## 3. 건드리는 파일

- `src/game/squat-runner.ts` — `cueText()` + draw(바 구간·화살표·색).
- `tests/squat-runner.test.ts` — cue 3케이스 (앉기까지 N초 / 지금 앉아 / 일어서세요).
- `src/ui/help.ts` — 앉기/일어서기 규칙 문구.
- `docs/UPDATELOG.md` + `CHANGELOG.md` — 같은 날짜 섹션에 덧붙이기.
