# 2인 별자리 새玩法 설계 (2026-09-23)

> 이전 방식(고정된 별 2개를 양손으로 0.8초 잡기)은 가만히 있어도 돼서 재미가 없다는
> 피드백을 받아, 아래 3가지를 합친 새 방식으로 바꾼다.
> 1번 순서대로 잇기 + 3번 60초 몇 개 + 5번 랜덤 위치.

## 새 규칙 (쉬운 말)

1. 별이 매번 다른 자리에 3~5개 나타나요.
2. 1번 별부터 순서대로 손 동그라미를 가져가세요 (어느 손이든 돼요).
3. 별 하나에 0.3초 대면 선이 이어지고 다음 별로 넘어가요.
4. 끝까지 이으면 별자리 1개 완성! 별 개수 × 10점 (3개면 30점, 5개면 50점).
5. 완성하자마자 새 별자리가 다른 자리·다른 모양으로 나와요.
6. 60초 동안 많이 완성할수록 점수가 올라가요 (콤보 보너스도 그대로).

## 판정 기준

- 어느 손(왼손·오른손)이든 현재 번호 별에 닿으면 인정돼요.
  (화면이 셀카 미러라 좌우가 바뀌어 보여도 헷갈리지 않게, 손을 가리지 않아요.)
- 동그라미 중심(손바닥 중심)이 별 중심에 화면 너비의 10% 이내로 가까워야 해요.
  (640px 화면은 64px, 1280px 화면은 128px 이내.)
- 0.3초 동안 대고 있으면 다음 별로 넘어가요. 손을 떼면 0초부터 다시 재요.
- 순서가 아닌 별(예: 1번을 안 하고 2번)에 손을 대도 아무 일도 없어요.

## 별 위치 정하기

- 가로: 화면 너비의 12%~88%, 세로: 화면 높이의 15%~60% (손이 닿는 범위).
- 별 사이는 최소 화면 너비의 15% 이상 띄워서 몸을 움직이게 해요.
- 자리가 겹치면 최대 50번까지 다시 뽑아요.
- 별 개수는 3~5개 랜덤 (테스트에서 같게 나오도록 게임 안에 작은 난수 생성기 사용).

## 화면 그리기

- 완성한 별: 밝은 노랑 + 이어진 선은 실선.
- 아직 남은 별: 옅은 색 + 이어질 선은 점선 (어떤 모양이 될지 미리 보여요).
- 지금 대야 할 별: 더 크게 + 흰색 링 + 번호 표시 + 0.3초 진행 링.
- 얼굴 마스크는 그리지 않아요 (`hideFace`, 이전 수정 유지).

## 점수·이벤트

- 별 하나 터치: `star` 이벤트 (0점, 소리와 안내만, "2번 별!").
- 별자리 완성: `pair` 이벤트 (별 개수 × 10점, 콤보 1 증가, 축하 파티클).
- 60초 제한은 게임 바깥 루프가 그대로 담당해요 (`main.ts`의 60초 챌린지).
