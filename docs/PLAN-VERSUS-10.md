# 대전 10종 확장 계획 (확정)

기존 3종(과일·줄다리기·수학) + 신규 7종(별·사이먼·별자리·ABC·댄스·풍선·좀비).
요가·분리수거는 제외: 반쪽 화면 구현 난이도 + 학생 충돌 안전.
실패 시 중단·보고 (수정 없이 로그 전달).

## 제외 사유

- 요가: 전사·삼각의 다리·팔 벌림이 반쪽 폭을 넘고 옆 사람과 충돌. 축소판도 버리고 제외.
- 분리수거: 중앙 줍기+양통 운반의 전신 이동이 충돌 위험 최대, 구현 복잡도 최고.
- 1P 12종 코드는 `skeleton-idea`에 그대로 둔다 (읽기 전용 참조).

## W0. 공통 인프라

- `versus-main` if/else → 레지스트리 맵 (id → 생성함수).
- `AttackBus` kind 확장: `dark`(먹별) · `heavy`(무거운 풍선) · `rush`(좀비 가속) ·
  `offbeat`(박자 단축). 쿨 5초·지속 3초 규칙 재사용.
- 가이드 렌더러 최소 부활: 댄스 10종 막대인간만 (마스크·파티클 제외).
- `VersusId`·`VERSUS_METAS`·router·랜딩 그리드 확장 (3→10장).
- 테스트: 라우터·메타·attack 쿨타임.

## W1. 별·사이먼·별자리 → 0.5.0

- 별잡기 대전: 반쪽 스폰(공유 패턴·미러), 별 +10, 3콤보마다 먹별(잡으면 -5).
- 사이먼 대전: 공유 지시 라운드, 먼저 +20·뒤따라 +10, 먼저 푼 쪽 안개 3초.
- 별자리 대전: 반쪽 3~5별·공유 시드 미러 배치, 먼저 완성 + 안개 3초.
- 게임별 단위테스트 (점수·선착순·방해·미러).

## W2. ABC·댄스·풍선 → 0.6.0

- ABC 대전: 공유 글자 라운드, 1초 유지, 먼저 +20·뒤따라 +10, X·A 제외 6종, 안개 3초.
- 댄스 대전: 공유 동작·박자 시퀀스, 적중 +10, 3연속 적중이면 상대 박자 단축 5초.
  넓은 동작(T/Y)은 허용치 완화. 가이드 그림 부활분 사용.
- 풍선 대전: 반쪽 풍선(공유 스폰·미러), 헤딩 +5, 낙하는 자기 콤보만 리셋,
  3콤보마다 상대에게 풍선 1개 추가.
- 게임별 단위테스트.

## W3. 좀비 + 중앙선 가드 → 0.7.0

- 좀비 대전: 반쪽별 3레인, 회피 +10, 5연속 회피면 상대 좀비 가속 1.5배 5초.
- 중앙선 가드 (전 종목 공통): 자기 반쪽을 벗어나면 해당 쪽 점수 정지 +
  "중앙선을 넘지 마세요! 제자리로" 경고. 준비 화면에 "서로 1m 이상" 1줄,
  도움말 공통 1줄 ("중앙선을 넘으면 점수가 멈춰요").
- 테스트: 경계 안/밖 판정, 침범 시 tick 스킵, 복귀 후 재개.
