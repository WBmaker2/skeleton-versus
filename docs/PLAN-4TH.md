# 4차 확장 계획 — 18번째 두더지 잡기 대전 (구현 완료, 0.11.0)

> 60초 · 카메라 1대 · 세로 2분할 · 왼쪽 P1 / 오른쪽 P2 · 자기 반쪽에서 손으로 두더지 잡기
> 바닥 3곳 + 측면 3곳, 총 6개 구멍. 랜덤으로 한 마리씩 올라옴. 맞으면 표정이 바뀌며 내려감.
> 아래 두더지는 위로 올렸다 내리찍기, 측면 두더지는 반대쪽으로 갔다가 쳐야 인정.
> 시간이 지날수록 빨라져 어려워짐.

## 1. 한눈에 보기

- 이름: 두더지 잡기 대전 (`versus-mole`, 난이도 쉬움, 반응·순발력)
- 방법: 자기 반쪽 구멍에서 올라온 귀여운 두더지를 손바닥으로 때려 잡는다. 잡을 때마다 +10점.
- 핵심 재미: 그냥 손을 대면 안 되고, 아래는 `위로 들었다가 내리찍기`, 측면은 `반대쪽으로 갔다가 휘두르기`로 쳐야 한다. 가만히 올려두거나 한 방향으로만 비비면 무효.
- 승부: 60초 뒤 점수가 높은 쪽이 승리. 순수 레이스 + 5연속마다 상대 두더지 가속 방해.
- 앉아서 가능 (손만 보이면 됨). 서서·앉서 둘 다 됨.

## 2. 공통 전제 (다른 대전과 동일)

- 60초·세로 2분할·자기 반쪽·중앙선 가드 그대로 (몸통이 선을 넘으면 그쪽 점수 정지 + 경고, 손 뻗기는 허용).
- 같은 랜덤 씨드로 양쪽에 같은 순서·같은 구멍이 나온다. 왼쪽/오른쪽만 뒤집어서 공정하게 (미러).
- 시작: T자세 5초 → 3,2,1 시작. 각자 키에 맞게 따로 보정 (어깨너비 기준).
- 속도·거리는 전부 어깨너비로 나눠서 계산 (키가 달라도 공평).
- 한 명만 보이면 그쪽 점수만 오르고 "둘 다 보이게 옆으로 비켜주세요" 안내.

## 3. 구멍 자리 (반쪽당 6곳)

반쪽 너비를 `hw`, 반쪽 왼쪽 끝을 `lo`라 할 때:

- 바닥 3곳: `y = 높이 × 0.82`, `x = lo + hw × (0.2 / 0.5 / 0.8)`
  - 바닥에 납작한 구멍 그림, 두더지가 아래에서 위로 쑥 올라옴.
- 측면 3곳: 바깥쪽 벽에 세로로 3곳, `y = 높이 × (0.3 / 0.5 / 0.7)`
  - P1은 왼쪽 벽 (`x = lo + hw × 0.12`), P2는 오른쪽 벽 (`x = lo + hw × 0.88`)
  - 바깥쪽에 붙여서 옆 사람과 부딪치지 않게 한다. 옆이 아닌 앞을 향해 치기 (도움말 1줄).
- 구멍 크기는 어깨너비 × 0.9 지름, 두더지 얼굴은 구멍보다 살짝 작게.
- 화면이 거울로 보여도 번호·글자는 정상으로 표시 (기존 거울문자 수정 규칙 따름).

```
[ P1 반쪽 예시 ]
벽① ●          ← 측면 위 (왼쪽 벽)
벽② ●          ← 측면 가운데
벽③ ●          ← 측면 아래
＿＿＿ ＿＿＿ ＿＿＿  ← 바닥 3곳 (①②③)
```

## 4. 두더지 상태·표정 (귀여움 규칙)

- 상태: `숨음 → 올라오는중(0.25초) → 나와있음(유지시간) → 내려가는중(0.25초) → 숨음`
- 한 번에 반쪽당 1마리만 나온다. 잡히거나 유지시간이 끝나면 0.2초 쉬고 다음 마리.
- 다음 구멍은 랜덤, 단 직전 구멍은 제외 (같은 자리 연속 안 나옴).
- 평소 표정: 눈 똘망 + 미소. 맞은 순간: `>_<` 윙크 + 볼터치 + 별 파티클, 0.2초만에 쏙 내려감.
- 놓쳐서 내려간 두더지는 졸린 표정 (`-_-`)으로 내려감 (맞은 것과 구별됨).
- 색: 몸통 밤색, 볼 분홍, 구멍은 고동색 타원. 방해(가속) 중에는 두더지 모자가 분홍색으로 표시.

## 5. 손 움직임 규칙 (핵심 판정)

손바닥(양손 중 아무 손) 중심이 두더지 얼굴 원 안에 들어온 순간, 아래 예비동작을 만족해야 때린 것으로 인정.

### 5-1. 바닥 두더지: 위로 들었다가 내리찍기

- 때리기 전 500ms 안에 손이 `위로 0.4어깨너비 이상 올라갔다가 아래로 방향을 바꾼` 기록이 있어야 함.
- 아래에서 좌우로만 비비거나 가만히 올려두면 무효 ("위에서 내려찍어 잡아!" 안내 0.5초 표시).
-イメージ: 모기 잡듯 위에서 톡 내리찍기.

### 5-2. 측면 두더지: 반대쪽으로 갔다가 휘두르기

- 때리기 전 500ms 안에 손이 `두더지 반대쪽으로 0.4어깨너비 이상 갔다가 두더지 쪽으로 방향을 바꾼` 기록이 있어야 함.
- 예: 왼쪽 벽 두더지 → 손이 먼저 오른쪽으로 갔다가 왼쪽으로 휘둘러야 인정. 오른쪽 벽은 반대.
- 측면에서만 왔다갔다 하거나 가만히 대면 무효 ("반대쪽으로 갔다가 쳐!" 안내 표시).

### 5-3. 공통 무효 조건

- 아래서만 움직이거나 측면에서만 움직이면 때릴 수 없음 (위 규칙의 예비동작이 없으면 무조건 무효).
- 손이 두더지에 닿아도 예비동작이 없으면 점수 없음·콤보 유지 (감점 없음, 초보자 배려).
- 손이 여러 개여도 한 마리는 1회만 인정 (맞은 뒤 300ms 연타 방지 쿨).
- 손바닥이 화면에 안 보이면 판정 안 함 (손등·주먹도 손바닥 점으로 통일, 기존 `palmOf` 재사용).

## 6. 점수·콤보·방해

- 잡기 1마리 +10점, 콤보 1 증가. 놓치면(시간 지나 내려감) 콤보만 리셋, 감점 없음.
- 5연속 잡을 때마다 상대 두더지 가속 1.5배 5초 (`rush` 재사용, 좀비·레이저와 동일).
  - 쿨타임 5초는 `AttackBus`가 관리. 상대 화면 위에 "상대의 방해! 두더지 가속 5초" 1초 표시.
  - 가속 중에는 유지시간·올라오는 속도가 1.5배 빨라짐 + 모자 분홍색.
- 먼저 잡기 보너스는 없음 (동시에 같은 순서가 나오지만 각자 잡는 속도로 승부, 순수 레이스).
- 축하: 잡을 때마다 작은 별 파티클, 5콤보마다 크게 축하 (`VersusLoop` 축하 목록에 `mole` 추가).

## 7. 난이도 상승 (시간이 지날수록 빨라짐)

60초 동안 유지시간·출현간격이 점점 짧아짐 (선형):

| 시간 | 나와있는 시간 | 다음 마리까지 쉼 | 체감 |
| --- | --- | --- | --- |
| 0~20초 | 1.5초 | 0.6초 | 천천히, 익히기 |
| 20~40초 | 1.1초 | 0.4초 | 보통 |
| 40~55초 | 0.85초 | 0.25초 | 빠름 |
| 55~60초 | 0.7초 | 0.15초 | 매우 빠름, 막판 뒤집기 가능 |

- 올라오는중·내려가는중 0.25초는 고정 (너무 빠르면 안 보임).
- 가속 방해(`rush`)가 걸리면 위 시간 ÷ 1.5.
- 느린 기기(절전 표시)에서는 파티클 절반, 추론 절반 규칙 그대로.

## 8. 공정성 (공유 시드·미러)

- 라운드 시작 시 씨드 1개 → 60초치 구멍 순서 미리 생성 (예: `[바닥2, 측면1, 바닥1, ...]`).
- P1은 그대로, P2는 좌우 뒤집기 (바닥 왼쪽↔오른쪽, 측면 왼쪽벽↔오른쪽벽).
- 난이도 시간표도 양쪽 동일. 방해 가속만 각자 다르게 걸림.
- 겹침·좌우바뀜은 기존 나누기(코 x좌표 + 0.5초 스무딩) 그대로 사용.

- 랜딩: `effect: '반응·순발력'`, 카드 아트 1장 추가 시 `versus-card-art-prompts.md`에 프롬프트 기록.

### meta 도움말 초안 (7줄)

1. 왼쪽에 P1, 오른쪽에 P2가 서세요 (둘 다 화면에 보여야 함)
2. 구멍에서 올라온 두더지를 손바닥으로 때려 잡으세요 (+10점)
3. 바닥 두더지는 손을 위로 들었다가 내려찍어야 잡혀요
4. 옆쪽 두더지는 반대쪽으로 갔다가 휘둘러야 잡혀요 (가만히 대면 안 잡힘)
5. 5번 연속 잡으면 상대 두더지가 5초 동안 빨라져요
6. 앉아서도 할 수 있어요 (손만 보이면 됨, 옆이 아닌 앞을 향해 치기)
7. 60초 뒤 점수가 높은 쪽이 승리!

## 10. 테스트 (예정 +12개)

- 구멍 미러: 같은 순서가 P1/P2에서 좌우 대칭으로 나오는지.
- 랜덤: 직전 구멍과 같은 자리가 연속으로 안 나오는지 (100회 생성).
- 바닥 인정: 위로 0.4어깨너비 이상 갔다가 내려오며 닿으면 +10.
- 바닥 무효: 아래에서 좌우로만 움직이며 닿으면 0점·콤보 유지.
- 측면 인정: 반대쪽으로 갔다가 휘둘러 닿으면 +10.
- 측면 무효: 측면에서만 왔다갔다하며 닿으면 0점.
- 표정: 맞으면 `hit` 표정으로 0.2초만에 내려감, 놓치면 `sleepy`로 내려감.
- 난이도: 0초 유지 1.5초 → 55초 유지 0.7초 확인.
- 방해: 5콤보마다 `rush` 전송, 쿨 5초·지속 5초(기존과 달리 5초, 화면에 표시).
- 연타방지: 맞은 뒤 300ms 안 추가 타격 무시.
- 축하 이벤트: `mole` 타입이 VersusLoop 축하 목록에 있음.
- 라우터·메타: id·번호·랜딩 등록 확인.

## 11. QA·안전·예외

- 거리 2.5~3.5m, 전신 아니어도 손·어깨만 보이면 됨 (어깨너비가 기준이므로 어깨는 꼭 보이게).
- 옆 사람과 부딪치지 않게 바깥쪽 벽 배치 + "앞을 향해 치기" 도움말. 중앙선 가드는 몸통 기준이라 손을 뻗어도 경고 안 뜸.
- 좁은 교실: 앉음 모드 가능, 팔만 움직이면 됨.
- 손이 가려지면 판정 멈춤 + "손이 보이게 해주세요" 안내 (점수 감점 없음).
- 저사양: 30fps 미만이면 절전(파티클 절반·추론 절반), `VERSUS-QA.md`에 18종 행 추가 후 실측 (미실시로 시작).
- 색약: 맞음/놓침을 색이 아닌 표정(`>_<` vs `-_-`)+모자 색+문구로 구별.
