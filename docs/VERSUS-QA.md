## 실기기 확인 (직접 해보고 체크)

공통 (어떤 기기에서든 먼저):

- [ ] 거리 2.5~3.5m에서 둘이 전신으로 들어오는지
- [ ] 밝은 형광등·역광에서 코 추적이 튀지 않는지
- [ ] 가운데선 근처에서 P1/P2가 뒤바뀌지 않는지 (0.5초 스무딩)
- [ ] 겹쳐 섰을 때 점수가 멈추고 안내가 나오는지
- [ ] 중앙선을 넘었을 때 해당 쪽만 멈추고 경고가 나오는지
- [ ] 세로 화면(휴대폰)에서 점수판이 겹치지 않는지
- [ ] 오프라인(두 번째 방문, 와이파이 끔)에서 실행되는지

성능 (저사양 기기·크롬북에서, 결과 화면의 최저 fps를 적기):

- [ ] 30fps 근처가 나오는지 (결과 화면 최저 fps: ___fps)
- [ ] 우하단 `절전` 표시가 뜨고 게임이 이어지는지
- [ ] 절전에서 빨라지면 표시가 사라지는지

종목별 (각 1판씩, 어색하면 횟수·수치를 적기):

- [ ] 수학: 같은 문제가 양쪽에 보이고 먼저 푼 쪽이 +20인지
- [ ] 과일: 양쪽에 같은 종류가 대칭 위치에 나오는지
- [ ] 줄다리기: 줄·박자바가 보이고 Perfect에 2칸 당겨지는지
- [ ] 별·사이먼·별자리: 대칭 출제·선착순 보너스(+20/+10)가 체감되는지
- [ ] ABC·댄스·풍선: 글자·동작·풍선이 반쪽에 잘 보이고 판정이 공정한지
- [ ] 좀비: 3레인 회피가 반쪽에서 되는지, 가속 공격이 체감되는지
- [ ] 펀치: 휙 쳐야 인정되고 천천히 대면 무효인지 (너무 짜면 4→3으로 완화 예정)
- [ ] 박수: 떼었다 합쳐야 카운트되고 붙인 채로는 안 되는지
- [ ] 균형: 발목 게이트("발목이 보이게")가 잘 뜨고, 흔들림에 리셋이 너무 잦지 않은지
- [ ] 릴레이: 순서 표시가 보이고 틀리면 처음부터 되는지
- [ ] 달리기: 무릎 카운트가 실제 걸음과 맞는지 (누락이 잦으면 임계 완화 예정)
- [ ] 파워: 굽힘·폄 1왕복이 1회로 세어지는지
- [ ] 레이저: 2초 안에 피할 시간이 충분한지 (빡빡하면 2.5초로 완화 예정)
- [ ] 두더지: 바닥은 내려찍어야·옆쪽은 휘둘러야 잡히고 가만히 대면 안 잡히는지, 갈수록 빨라지는지 (미실시)
- [ ] 좁은 교실에서 앉아서 과일·수학·별·사이먼·ABC·댄스·풍선·좀비·펀치·박수·균형·릴레이·레이저·두더지가 되는지 (줄다리기·달리기·파워는 서서만)
