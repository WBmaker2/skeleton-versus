# 2인 대전 스켈레톤 새 사이트 계획 (VERSUS-PLAN)

> 승인일: 2026-09-26 / 카메라 1대 · 세로 2분할 · 1분 승부 · 별도 프로젝트 `skeleton-versus`

## 1. 한눈에 보기

- 기존 `skeleton-idea`(1인 12종)는 그대로 둔다. 새로 `skeleton-versus`를 만든다.
- 카메라는 1대. 두 사람이 한 화면에 들어와 왼쪽(P1) / 오른쪽(P2)으로 나뉜다.
- 60초 동안 같은 미션을 하고 점수로 승부를 낸다.
- 1차 3종: 과일 베기 대전 / 스쿼트 줄다리기 / 수학 달리기.
- 방해는 억지로 넣지 않고, 잘하는 보상이 자연스럽게 방해가 되게 한다.

## 2. 공통 대전 틀

- 화면: 세로 2분할. 가운데 선 + 위쪽에 `P1 점수 : 점수 P2` + 가운데 남은 시간.
- 같은 랜덤 씨드로 양쪽에 같은 패턴이 나온다. 왼쪽/오른쪽만 뒤집어서 공정하게.
- 시작: 두 사람이 T자세 5초 -> 3,2,1 시작. 각자 키에 맞게 따로 보정한다.
- 끝: `P1 승리 / P2 승리 / 무승부` + 다시 대전 버튼(금빛 펄스).
- 한 명만 보이면 그쪽만 점수가 오르고 "둘 다 보이게 옆으로 비켜주세요" 안내가 나온다.

## 3. 사람 나누는 방법 (핵심 기술)

- MediaPipe `numPoses:2`로 2명을 찾는다. 코(nose) x좌표로 왼쪽/오른쪽을 정한다.
- 0.5초 정도 부드럽게 해서 좌우가 자꾸 바뀌지 않게 한다.
- 겹치면 점수를 잠시 멈추고 경고만 보여준다.
- 무거우면 해상도를 720p -> 640으로 낮추고, 파티클을 절반으로 줄인다.

```
카메라 1대 -> 2명 포즈 -> 왼쪽/오른쪽 나누기 -> 각자 게임 2개 돌리기 -> 점수 합산 -> 승자
```

## 4. 게임별 규칙

### 4-1. 과일 베기 대전 (먼저 만듦, 쉬움)

- 방법: 양손으로 과일을 벤다. 폭탄은 -15점.
- 점수: 과일 +10. 3번 연속 베면 상대에게 `썩은 과일`(회색, 베면 -5점) 1개 보냄.
- 왜 자연스러운가: 잘 베는 실력이 곧 공격이다. 폭탄을 보내지 않아 너무 아프지 않다.
- 쿨타임 5초. 상대 화면 위에 "P1의 방해!" 1초 표시.

### 4-2. 스쿼트 줄다리기 (중간)

- 방법: 앉았다 일어서면 줄을 당긴다. 2초 박자에 맞추면 2칸 당김(Perfect).
- 승부: 점수 대신 가운데 줄이 넘어간 쪽이 이긴다. 보면 바로 안다.
- 파워 당기기: 5번 연속 Perfect면 3초 동안 상대 화면이 흔들리고 상대 줄이 절반만 올라간다.
- 왜 자연스러운가: 스쿼트를 잘하는 보상이 공격이다. 기존 스쿼트 판정(무릎 각도, 300ms 유지) 그대로 쓴다.

### 4-3. 수학 달리기 대전 (쉬움)

- 방법: 문제가 나오면 몸을 움직여 정답 구역(왼쪽/가운데/오른쪽)으로 가서 손을 든다.
- 점수: 먼저 맞추면 +20, 나중이면 +10, 틀리면 -5. 먼저 맞추는 게 중요하다.
- 방해: 먼저 맞춘 사람이 상대에게 `안개 3초`(숫자가 흐릿해지지만 가려지진 않음).
- 왜 자연스러운가: 빨리 푸는 실력이 방해가 된다. 숫자를 바꾸지 않아 불공정하지 않다.

## 5. 새 프로젝트 구성

새 폴더: `skeleton-versus/` (기존 옆에 신설, 별도 배포)

```
skeleton-versus/
  docs/VERSUS-PLAN.md
  docs/UPDATELOG.md
  src/
    versus/ (신규 핵심)
      split.ts         # 왼쪽/오른쪽 나누기
      dual-board.ts    # P1/P2 점수 + 승자
      versus-loop.ts   # 2인용 게임 루프 (60초 동기)
      attack.ts        # 방해 보내기 (쿨타임 관리)
      versus-stage.ts  # 2분할 그리기 + 가운데선
    versus-games/
      fruit-duel/
      squat-tug/
      math-dash/
    pose/mediapipe-dual.ts  # numPoses:2
    ... landing, ui, calibration은 기존에서 복사 후 versus용으로 간단하게
```

가져옴: `geometry(손바닥, 무릎각도)`, `ScoreBoard`, 파티클, 보정, 카메라 선택.
새로 만듦: 좌우 나누기, 듀얼 루프, 방해, 승자 화면, versus 고르기 화면(3카드).

배포: 새 repo면 `base: '/skeleton-versus/'`. PWA 이름도 따로 해서 캐시가 섞이지 않게 한다.

## 6. 만드는 순서

1. 문서 + 새 폴더 뼈대 (지금 단계)
2. 대전 코어(나누기+듀얼루프+2분할 화면) 먼저
3. 과일 -> 스쿼트 -> 수학 순서로 하나씩 (각각 테스트 포함)
4. QA: 2.5~3.5m 거리, 조명, 좌우 바뀜, 저사양 30fps, 업데이트 내역 기록

## 7. 위험과 대책

- 겹쳐서 사람이 바뀜 -> 부드럽게 + 겹치면 일시정지
- 느려짐(2명 인식) -> 해상도 낮춤 + 파티클 절반
- 키 차이 불공정 -> 각자 따로 보정
- 좁은 교실 -> 앉음 모드 안내 (스쿼트는 서서만)
